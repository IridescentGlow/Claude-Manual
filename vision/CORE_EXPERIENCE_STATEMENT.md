# CORE EXPERIENCE STATEMENT
Solarisx Portfolio — Version 3.0 (retrofit)

Canonical. Outranks CREATIVE_DIRECTION_BOARD.md and
UX_ARCHITECTURE_BLUEPRINT.md on any conflict.

## Statement

A visitor should leave feeling like they watched someone work a room they
clearly built — quietly, precisely, in full command of it — and then
witnessed one moment where that same command revealed a deeper layer of
craft, still entirely in character. Not a departure from the composure.
Proof of how much control it contains.

## What This Means

- Respected, not sold to.
- Impressed before being told why.
- Trust earned, not requested.
- Memorable because something true was revealed — not because something
  impressive happened. ("I understand this person's level of control," not
  "that animation was cool.")
- Feels like one specific person, not a template.

## How To Use This

- Ambiguous decision → does this move a visitor toward this feeling, or is
  it just technically correct?
- Technically sound but serves none of the above → reconsider it.
- Conflicts with another canonical document → this one wins.
